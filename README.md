# Patente B - ئەپ

ئەم فۆڵدەرە ئەپەکە بۆ App Store و Google Play ئامادە دەکات.
کۆدی سەرەکی لە `www/index.html` ـە (هەمان ماڵپەڕەکەیە).

## هەنگاوەکان
1. هەژماری GitHub دروست بکە، ڕیپۆیەکی نوێ بە ناوی `patente-app` (Private).
2. هەموو فایلەکانی ئەم فۆڵدەرە بار بکە (Upload files).
3. هەژماری Codemagic (codemagic.io) بکەرەوە، بە GitHub بچۆ ژوورەوە، ڕیپۆکەت زیاد بکە.
4. ئایفۆن: لە Codemagic ئینتیگریشنی App Store Connect زیاد بکە، کلیلی API بۆ Apple.
5. ئەندرۆید: فایلی keystore دروست بکە و لە Codemagic زیادی بکە.
6. Build بکە. فایلی `.ipa` بۆ App Store و `.aab` بۆ Google Play دروست دەبێت.

## ئاگاداری
- ئەپەکە پەیوەستە بە Supabase، بۆیە ئینتەرنێت پێویستە.
- بڵاوکردنەوە بۆ Apple و Google پێویستی بە سیاسەتی تایبەتمەندی (Privacy Policy) و وێنەی شاشە هەیە.
